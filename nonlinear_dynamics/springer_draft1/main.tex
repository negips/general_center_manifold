\abstract{Center-manifold approximation of generic large non-linear system at a multiple co-dimension bifurcation point is considered. The system is perturbed with small parameter perturbations and harmonic forcings so that the system is displaced slightly from the original bifurcation point. We take the ``extended systems'' approach to analyze such systems which elevates parameter perturbation as well as harmonic forcings as state variables and extends the dimensionality of the center-subspace. The new subspace structure is explicitly evaluated, which is non-trivial when there is resonance between the angular frequences of the extended modes and the eigenvalues of the unperturbed system. Despite the extension of the operators, It is shown that the construction of an asymptotic center-manifold for such an extended system in fact only requires operations on the original linearized system at bifurcation. A key consequence of taking the ``extended systems'' perspective is that algorithms for parameter perturbation, harmonic forcing and unperturbed system center-manifolds can be unified into a single algorithm. A Ginzburg-Landau model near bifurcation is used to demonstrate the validity of the approach based on the extended system.}

%We develop a systematic algorithmic framework for constructing asymptotic center manifolds of high-dimensional nonlinear systems subject to simultaneous parameter perturbations and harmonic external forcing. Rather than treating these effects separately via classical non-autonomous theory or perturbative unfolding, we employ an "extended system" formulation that incorporates parameters and forcing phases as additional state variables. This elevates a non-autonomous problem to a higher-dimensional autonomous one, to which classical center manifold theory directly applies. The main contribution is showing that despite enlarging the center subspace dimension, the asymptotic construction requires only operations on the original unextended linearized operator. This computational advantage is crucial for large-scale discretized systems (PDEs, finite elements) where matrix operations scale prohibitively with dimension. We derive explicit formulae for the extended eigenvector structure, handling both resonant and non-resonant cases. A unified algorithm constructs the manifold and its reduced dynamics (normal form) to arbitrary order, applicable to all three scenarios: unperturbed systems, parameter perturbations, and harmonic forcing. As a complementary approach to spectral submanifold (SSM) methods, our framework extends to non-hyperbolic bifurcation points where SSM constructions fail. Numerical validation is provided using a Ginzburg-Landau model near bifurcation.

%Generic large non-linear systems at a multiple co-dimension bifurcation point is considered. Such systems are perturbed with small parameter perturbations and harmonic forcings so that the system is displaced slightly from the original bifurcation point. The approach taken to analyze such a system is to create a new extended system which incorporates system perturbation as well as harmonic forcings as additional degrees of freedom and extend the dimensionality of the center-subspace. The subspace structure in the new directions is explicitly evaluated, which is non-trivial when there is resonance between the angular frequences of the extended modes and the eigenvalues of the unperturbed system. It is further shown that the construction of an asymptotic center-manifold for such an extended system in fact only requires operations on the original linearized system at bifurcation. Algorithms are presented for the explicit construction of the new tangent space as well as for the asymptotic center-manifold approximations. A Ginzburg-Landau model near bifurcation is used to demonstrate the validity of the approach based on the extended system.
